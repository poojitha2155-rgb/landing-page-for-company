# 🚀 Future Akshita Company

## Internship & Talent Management Platform

> A centralized platform connecting students, companies, colleges, counsellors, and administrators to manage internships, talent discovery, applications, selection, joining, and completion.

![Future Akshita Architecture](assets/future-akshita-architecture.png)

---

## 📌 Project Overview

Future Akshita Company is a web-based Internship and Talent Management Platform designed to connect:

- 🎓 Students
- 🏢 Companies
- 🏫 Colleges / Institutions
- 👨‍🏫 Career Counsellors
- 🛡️ Platform Administrators

The platform manages the complete internship lifecycle:

```text
Registration
     ↓
Profile Creation
     ↓
Opportunity Discovery
     ↓
Eligibility Checking
     ↓
Application
     ↓
Shortlisting
     ↓
Interview
     ↓
Selection
     ↓
Joining
     ↓
Completion
     ↓
Digital Certificate
⭐ Key Features
👨‍🎓 Student Module

Students can:

Create an account
Build a professional profile
Upload resumes
Add skills
Add projects
Add education details
Search internships
Filter opportunities
Check eligibility
Apply for internships
Track applications
Attend interviews
View selection status
Track joining
Track completion
Receive digital certificates
🏢 Company Module

Companies can:

Register
Complete company verification
Create company profiles
Post internships
Define eligibility requirements
View applicants
Shortlist candidates
Schedule interviews
Select candidates
Track joining
Track internship completion
🏫 College / Institution Module

Institutions can:

Register their institution
Manage student information
Verify student credentials
Map courses and branches
Connect students with opportunities
Manage company partnerships
Track student outcomes
Manage MoU information
👨‍🏫 Counsellor Module

Counsellors can:

View student profiles
Provide career guidance
Identify skill gaps
Recommend opportunities
Suggest learning paths
Track student progress
🛡️ Admin Module

Administrators can:

Verify companies
Verify institutions
Manage users
Manage opportunities
Monitor applications
Manage partnerships
Monitor platform activity
Generate reports
View analytics
Manage platform configuration
Maintain audit records
